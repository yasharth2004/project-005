# User Guide - Samsung PRISM RAG Chatbot

## 🚀 Getting Started

### Welcome to Samsung PRISM RAG Chatbot
The Samsung PRISM RAG Chatbot is an AI-powered assistant designed to help you navigate the Samsung PRISM (Program for Innovation and Student Mentorship) program. Whether you're a student looking for worklet-specific information or someone seeking general program details, our intelligent system provides accurate, contextual responses.

## 👤 Account Creation & Login

### 📝 Creating Your Account

#### Step 1: Choose Your Role
When you first visit the signup page, you'll be presented with two role options:

**🎓 Student**
- Access to personalized worklet information
- Worklet-specific AI responses
- Privacy-protected data access
- Requires valid worklet ID

**👑 Admin**
- Full system access
- File management capabilities
- User administration
- System monitoring tools

#### Step 2: Provide Your Information
Fill in the required details:
- **Full Name**: Your complete name as it should appear in the system
- **Email Address**: A valid email address (will be used for login)
- **Password**: Create a secure password (minimum 6 characters)
- **Confirm Password**: Re-enter your password for verification

#### Step 3: Worklet Validation (Students Only)
If you selected "Student" role:
1. Enter your assigned worklet ID
2. The system will validate your worklet in real-time
3. Upon successful validation, you'll see your worklet details
4. If the worklet ID is invalid, you'll receive an error message with guidance

#### Step 4: Account Confirmation
- Review your information
- Click "Create Account"
- Upon successful creation, you'll be automatically logged in
- You'll receive a welcome message confirming your account creation

### 🔐 Logging In
1. Navigate to the login page
2. Enter your email and password
3. Click "Sign In"
4. You'll be redirected to the main application

### 🎨 Theme Customization
Both login and signup pages feature a theme toggle button in the top-right corner:
- **Light Mode**: Professional, clean interface with Samsung's light theme
- **Dark Mode**: Modern dark interface with reduced eye strain
- Your theme preference is automatically saved for future visits

## 🛠️ Troubleshooting

### Common Issues and Solutions

#### Login Problems
**Issue**: Cannot log in with correct credentials
**Solution**: 
- Verify email address format
- Check for typos in password
- Ensure account was successfully created
- Contact admin if issues persist

#### Worklet Validation Issues
**Issue**: Worklet ID not recognized during signup
**Solution**:
- Double-check worklet ID for typos
- Verify worklet ID with your mentor or admin
- Ensure worklet is active in the system
- Contact support with your worklet information

#### Theme Not Saving
**Issue**: Theme preference resets on page reload
**Solution**:
- Check if browser allows local storage
- Clear browser cache and try again
- Ensure JavaScript is enabled
- Try using a different browser

#### Chat Not Responding
**Issue**: AI responses are slow or not generating
**Solution**:
- Check internet connection
- Refresh the page and try again
- Verify you're logged in properly
- Contact admin if problem persists
